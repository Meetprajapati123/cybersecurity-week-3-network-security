## Objective

The objective of this practical is to perform an authorized network
security assessment of an isolated lab environment.

The assessment covers:

- Network discovery
- Nmap security scanning
- Service and OS detection
- Wireshark traffic analysis
- Nmap and Wireshark correlation
- Advanced network traffic investigation
- Basic vulnerability assessment
- Security hardening
- Before/after security verification

All testing was performed only on the authorized laboratory network.
